# + 버튼 펼침 · 문자 붙여넣기 / 직접 적기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈의 +를 "결제 직접 입력" 펼침 메뉴로 바꾸고, 새로 추가 맨 앞에 "카드 문자 붙여넣기 / 직접 적기" 분기를 두어 붙여 넣은 문자로 값을 채운 뒤 마지막 화면으로 보낸다(겹치는 결제는 경고).

**Architecture:** 붙여 넣은 글 해석은 순수 함수(`src/ledger/paste-sms.ts`, 기존 `parseSms`·`guessFromSms` 재사용)로 브라우저에서 한다. 저장은 기존 `createManualTx`에 겹침 확인 옵션을 더하고, 겹침 판단은 순수 함수(`src/ledger/overlap.ts`)로 단위 테스트한다. 화면은 `AddFlow`에 `mode`(choose · paste · form)를 두고 분기·붙여넣기 부품을 따로 만든다.

**Tech Stack:** Next.js 16(App Router, 서버 액션), React 19, Supabase(RLS), Vitest(단위·DB), Playwright(webkit, iPhone 13).

**Spec:** `docs/superpowers/specs/2026-10-08-add-paste-design.md`

## Global Constraints

- 모든 화면 문구는 한국어, 스펙의 문구를 그대로 쓴다: "결제 직접 입력", "어떻게 적을까요?", "카드 문자 붙여넣기", "받은 결제 문자를 붙여 넣으면 알아서 채워요", "직접 적기", "금액부터 하나씩 적어요", "결제 금액을 찾지 못했어요. 문자를 확인하거나 직접 적어 주세요.", "취소 문자예요. 원래 결제를 찾아 지워 주세요.", "결제 문자를 붙여 넣어 주세요.", "입력칸을 길게 눌러 붙여 넣어 주세요.", "이미 들어온 결제 같아요", "그래도 저장", "닫기".
- 메뉴는 3초 뒤 접힌다. 펼침·접힘 0.25초. 동작 줄이기면 움직임 없음.
- 겹침: 같은 가계부·같은 사람·같은 금액, |시각 차| ≤ 5분, 카드 승인 또는 직접 추가(취소 제외). 붙여넣기로 온 저장만 확인한다.
- 붙여 넣은 원문은 서버로 보내지 않고 저장하지 않는다.
- DB 구조(마이그레이션)는 바꾸지 않는다.
- 로컬 DB에 `supabase db reset`을 쓰지 않는다.

## Review Focus

1. 국민·현대가 아닌 카드사의 **취소 문자**를 붙여 넣으면 결제로 저장되면 안 된다 → 짐작 경로에서도 "취소"가 있으면 취소로 안내(Task 1 테스트).
2. 같은 문자를 **두 번 붙여 넣어** 저장하면 두 번째는 겹침 경고가 나와야 한다(직접 추가끼리도 겹침) → Task 2 DB 테스트.
3. 휴대폰이 **클립보드 읽기를 거부**하면 조용히 실패하지 말고 "입력칸을 길게 눌러 붙여 넣어 주세요."를 보여야 한다 → Task 4 화면 테스트.
4. 금액은 찾았지만 **시각이 없는 문자**는 빠진 항목(언제)만 묻고 마지막 화면으로 가야 한다 → Task 4 화면 테스트.
5. 메뉴를 펼친 뒤 **알약을 눌러 새로 추가가 열리면** 3초 타이머가 남아 있어도 오류 없이 접혀 있어야 하고, 다시 +를 누르면 다시 펼쳐져야 한다 → Task 3 화면 테스트.

```ts
import { parseSms } from "@/parsers";
import { guessFromSms } from "./sms-guess";

export type PasteRead =
  | { ok: true; amount: number; merchant?: string; occurredAt?: Date }
  | { ok: false; reason: "empty" | "no_amount" | "cancel" };

export const PASTE_ERROR = {
  empty: "결제 문자를 붙여 넣어 주세요.",
  no_amount: "결제 금액을 찾지 못했어요. 문자를 확인하거나 직접 적어 주세요.",
  cancel: "취소 문자예요. 원래 결제를 찾아 지워 주세요.",
} as const;

/**
 * 새로 추가 › 카드 문자 붙여넣기: 붙여 넣은 글에서 금액·가게·시각을 찾는다(브라우저에서, 원문은 보내지 않음).
 * 국민·현대 분석기가 먼저 읽고, 못 읽으면 문자 짐작으로 찾는다. 취소 문자는 결제로 만들지 않는다.
 */
export function readPastedSms(text: string, now: Date): PasteRead {
  const body = text.trim();
  if (!body) return { ok: false, reason: "empty" };
  const { result } = parseSms(body, now);
  if (result.kind === "cancel") return { ok: false, reason: "cancel" };
  if (result.kind === "approval") {
    return { ok: true, amount: result.amount, merchant: result.merchant, occurredAt: result.occurredAt };
  }
  // 분석기가 모르는 카드사도 취소 문자는 결제로 만들지 않는다
  if (body.includes("취소")) return { ok: false, reason: "cancel" };
  const g = guessFromSms(body, now);
  if (!g.amount) return { ok: false, reason: "no_amount" };
  return {
    ok: true, amount: g.amount,
    ...(g.merchant ? { merchant: g.merchant } : {}),
    ...(g.occurredAt ? { occurredAt: g.occurredAt } : {}),
  };
}
```

```ts
export const OVERLAP_MINUTES = 5;
export type OverlapRow = { userId: string; kind: string; amount: number; merchant: string; occurredAt: Date };

/** 붙여 넣어 저장하려는 결제와 겹치는(이미 들어온 것 같은) 거래. 취소는 보지 않는다. */
export function findOverlap(rows: OverlapRow[], t: { userId: string; amount: number; occurredAt: Date }): OverlapRow | null {
  const span = OVERLAP_MINUTES * 60_000;
  return rows.find((r) =>
    r.kind !== "cancel" && r.userId === t.userId && r.amount === t.amount
    && Math.abs(r.occurredAt.getTime() - t.occurredAt.getTime()) <= span) ?? null;
}
```

```ts
/** 가맹점 규칙(우리 가계부, 이름이 같을 때)의 분류. RLS로 다른 가계부 규칙은 보이지 않는다. */
export async function ruleCategoryFor(db: SupabaseClient, merchant: string): Promise<string | null> {
  const name = typeof merchant === "string" ? merchant.trim() : "";
  if (!name) return null;
  const { data } = await db.from("merchant_rules").select("category_id").eq("merchant_pattern", name).maybeSingle();
  return data?.category_id ?? null;
}
```

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { pushOverlay } from "./overlay-history";

const OPEN_MS = 3000;

/**
 * 홈 머리의 +(설계 2026-10-08 붙여넣기). 누르면 +가 ×로 돌고 왼쪽에 [결제 직접 입력]이 펼쳐진다.
 * 3초 동안 누르지 않거나, ×·바깥을 누르면 접힌다. 알약을 누르면 새로 추가(주소에 add=1)가 열린다.
 */
export function AddButton({ month }: { month: string }) {
  const href = `/?month=${month}&add=1`;
  const [open, setOpen] = useState(false);
  const box = useRef<HTMLDivElement>(null);

  // 열려 있는 동안만: 3초 타이머와 바깥 누르기
  useEffect(() => {
    if (!open) return;
    const timer = window.setTimeout(() => setOpen(false), OPEN_MS);
    const outside = (e: PointerEvent) => { if (!box.current?.contains(e.target as Node)) setOpen(false); };
    document.addEventListener("pointerdown", outside);
    return () => { window.clearTimeout(timer); document.removeEventListener("pointerdown", outside); };
  }, [open]);

  return (
    <div ref={box} className={`add-menu ${open ? "is-open" : ""}`}>
      {open && (
        <a
          href={href} className="add-pill"
          onClick={(e) => { e.preventDefault(); setOpen(false); pushOverlay(href); }}
        >
          결제 직접 입력
        </a>
      )}
      <button
        type="button" aria-label="결제 입력 메뉴" aria-expanded={open} onClick={() => setOpen((o) => !o)}
        className="add-plus grid h-10 w-10 place-items-center rounded-full text-[25px] text-accent"
      >
        <span aria-hidden>+</span>
      </button>
    </div>
  );
}
```

접힐 때의 0.25초 움직임: 알약을 바로 없애지 않고 `closing` 상태로 250ms 동안 `add-pill-out`(위 keyframes의 반대)을 보인 뒤 없앤다. `AddButton`에 `const [closing, setClosing] = useState(false);`를 두고, `setOpen(false)`를 부르던 곳(타이머·바깥·× 누르기)은 `close()`로 바꾼다:

```tsx
  function close() {
    if (reduced()) return setOpen(false);
    setClosing(true);
    window.setTimeout(() => { setOpen(false); setClosing(false); }, 250);
  }
```

+ 버튼은 `onClick={() => (open ? close() : setOpen(true))}`, 효과 안의 타이머·바깥 누르기도 `close()`를 부른다. 알약 `className={`add-pill ${closing ? "is-closing" : ""}`}`, CSS에 `.add-pill.is-closing { animation: add-pill-out .25s ease-in forwards; } @keyframes add-pill-out { to { opacity: 0; transform: translateX(14px) scaleX(.6); } }`, `closing`인 동안 `.add-menu`의 `is-open`은 빼서 ×가 +로 돌아간다(`className={`add-menu ${open && !closing ? "is-open" : ""}`}`). 알약을 눌러 새로 추가를 열 때는 움직임 없이 바로 `setOpen(false)`. `reduced()`는 `window.matchMedia("(prefers-reduced-motion: reduce)").matches`. 테스트의 "접힌 뒤 없음"은 250ms 뒤 확인되므로 `toHaveCount(0)`의 기본 기다림으로 통과한다.

```tsx
import { PASTE_ERROR, readPastedSms } from "@/ledger/paste-sms";
import { CheckButton } from "./check-button";

export type PasteFill = { amount: number; merchant?: string; occurredAt?: Date; categoryId: string | null | undefined };
const CLIP_FAIL = "입력칸을 길게 눌러 붙여 넣어 주세요.";

/** 카드 문자 붙여넣기: 글을 읽어 채울 값을 넘긴다(원문은 서버로 보내지 않는다) */
export function PasteStep({ now, onBack, onRead, onDirect }: {
  now: Date; onBack: () => void; onRead: (fill: PasteFill) => void; onDirect: () => void;
}) {
  const [text, setText] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [noAmount, setNoAmount] = useState(false);

  async function fromClipboard() {
    try {
      const t = await navigator.clipboard.readText();
      if (!t.trim()) throw new Error("empty");
      setText(t);
      setError(null);
    } catch {
      setError(CLIP_FAIL);
    }
  }
  function check() {
    const r = readPastedSms(text, now);
    setNoAmount(!r.ok && r.reason === "no_amount");
    setError(r.ok ? null : PASTE_ERROR[r.reason]);
    return r.ok;
  }
  async function read() {
    const r = readPastedSms(text, now);
    if (!r.ok) return false;
    // 규칙을 못 찾아도(연결 끊김 포함) 분류만 물으면 된다
    const categoryId = r.merchant ? await findRuleCategory(r.merchant).catch(() => null) ?? undefined : undefined;
    onRead({ amount: r.amount, merchant: r.merchant, occurredAt: r.occurredAt, categoryId });
    return true;
  }

  return (
    <>
      <div className="lx-bar">
        <button type="button" aria-label="뒤로" className="!text-[22px]" onClick={onBack}>‹</button>
        <span>카드 문자 붙여넣기</span>
        <span className="w-8" />
      </div>
      <div className="flex min-h-0 flex-1 flex-col justify-center gap-3 px-5">
        <textarea
          aria-label="결제 문자" value={text} onChange={(e) => setText(e.target.value)} rows={7}
          placeholder="여기에 결제 문자를 붙여 넣어요" className="paste-box"
        />
        <button type="button" onClick={fromClipboard} className="mx-auto px-4 py-2 text-sm font-semibold text-accent">붙여넣기</button>
        {error && <p role="alert" className="text-center text-sm text-danger">{error}</p>}
        {noAmount && <button type="button" onClick={onDirect} className="mx-auto text-sm text-muted underline">직접 적기</button>}
      </div>
      <div className="lx-cta">
        <CheckButton label="읽기" validate={check} run={read} />
      </div>
    </>
  );
}
```

```ts
function fromPaste(meId: string, now: Date, f: PasteFill): { draft: Draft; done: FieldKey[] } {
  const at = splitLocal(kstLocalValue(f.occurredAt ?? now));
  const draft: Draft = { amount: String(f.amount), merchant: f.merchant ?? "", categoryId: f.categoryId, date: at.date, time: at.time, userId: meId };
  const done: FieldKey[] = ["amount", "who"];
  if (f.merchant) done.push("merchant");
  if (f.categoryId !== undefined) done.push("category");
  if (f.occurredAt) done.push("when");
  return { draft, done };
}
```
