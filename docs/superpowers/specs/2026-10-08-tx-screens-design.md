# 거래 상세 · 새로 추가 · 밀어서 삭제 · 확인할 문자 설계

작성: 2026-10-08 · 상태: 사용자 승인(시안 21판에서 확정, "1번으로 진행하고 배포까지")

시안 페이지의 "거래 상세 · 새로 추가 · 삭제 (움직이는 시안)" 칸이 기준이다.
공개 저장소이므로 시안 주소는 적지 않는다.

## 1. 거래 상세 (거래 줄을 누르면)

**모양**
- 그 줄 자리에서 상세 화면이 커져 **화면 전체**를 채운다. 뒤의 홈은 살짝 작아지고 어두워진다.
- 상세 화면은 위에서부터 이렇게 놓는다.
  - 큰 분류 아이콘, 가게, 금액
  - 항목 목록: 금액 · 어디서 · 분류 · 언제 · 누가 · 카드(결제 수단)
  - "온누리상품권으로 결제" 체크(취소 거래 제외)

**고칠 수 있는 항목**
- **카드 문자로 들어온 거래**: 분류만 고칠 수 있다. 나머지 항목은 보기만 한다.
- **직접 추가한 거래**: 모든 항목을 고칠 수 있다.

**항목 고치기**
- 항목을 누르면 그 항목 한 화면이 오른쪽에서 밀려 들어온다.
- 질문은 화면 가운데에 나온다. [확인]을 누르면 저장하고 상세로 돌아오며, 바뀐 값이 반짝인다.

**닫기**
- "✕ 닫기"를 누르면 **하수구로 빨려 들어가듯** 그 줄로 들어간다.
  - 이동은 처음부터 부드럽게, 크기는 비율을 유지한 채 점점 빨리 작아진다.
  - 회전은 45°만 하고, 글자가 먼저 흐려진다. 전체 0.52초.
- 다 들어가면 그 자리에 파문이 퍼지고, 줄이 튕기며 반짝인다.

**그 밖**
- 메모, 사람 바꾸기 이외의 "더 보기", 원문 보기는 없앤다(메모 칸은 DB에 남긴다).
- 주소는 지금처럼 `?tx=<id>`를 쓴다. 서버가 거래를 읽고, 화면은 클라이언트에서 움직인다.

## 2. 새로 추가 (+ 버튼)

**열기**
- + 버튼 자리에서 화면이 커진다.

**입력 방식(쌓이는 입력)**
- 질문은 화면 가운데에 나온다. 순서는 금액 → 어디서 → 분류 → 언제 → 누가다.
- [다음]을 누르면 입력한 값이 위로 올라가 쌓인다.
- 쌓인 값을 누르면 그 질문으로 돌아가 다시 고칠 수 있다.
- 다섯 개가 다 쌓이면 "다 입력했어요"가 나오고 [저장하기]를 누른다.

**저장**
- 저장하면 하수구처럼 그 새 줄로 빨려 들어간다.

**항목별 입력**
- **금액**: 입력하는 즉시 한글 단위로 보인다.
  - 예: 13325 → "1만 3325", 123456789 → "1억 2345만 6789"
  - 0인 단위는 생략한다.
  - 실제 숫자는 화면 글자와 따로 기억한다.
- **언제**: 오늘 · 어제 · 그저께 중에서 고르고 시각을 정한다.
- **누가**: 구성원 닉네임 중에서 고른다.

## 3. 밀어서 삭제

- 홈의 거래 줄을 왼쪽으로 밀면 휴지통이 나온다. **직접 추가한 거래만** 해당한다.
- 휴지통을 누르면 확인 창("이 거래를 지울까요?")이 뜨고, 지우면 줄이 접히며 사라진다.
- **카드 문자 거래**는 밀면 살짝만 움직였다가 돌아온다. 그리고 "카드 문자로 들어온 거래는 지울 수 없어요"가 뜬다.

## 4. 확인할 문자

- 못 읽은 문자는 **모두 사용자에게** 보여 준다. 홈에 "확인할 문자가 N건 있어요"가 뜬다.
- 목록은 문자 원문 카드로 보여 주고, 카드마다 [무시]와 [거래로 등록]이 있다.
- **[거래로 등록]**
  - 새로 추가 화면이 열린다.
  - 문자에서 찾은 금액·가게·시각과 문자를 받은 사람을 **미리 쌓아 둔다.**
  - 빠진 항목만 물어본다.
  - "문자에서 찾은 내용을 미리 채웠어요. 틀리면 눌러서 고쳐 주세요." 안내를 보여 준다.
  - 저장하면 그 문자는 목록에서 빠진다.

## 5. 공통

- 휴대폰의 '동작 줄이기' 설정이 켜져 있으면 움직임 없이 바로 바뀐다.
- 저장·삭제는 서버가 다시 확인한다.
  - 카드 문자 거래는 분류·온누리 표시 말고는 고칠 수 없다.
  - 삭제는 직접 추가한 거래만 된다.
- 테스트
  - 단위: 한글 금액, 문자에서 값 찾기, 언제 → 날짜
  - DB: 기존 규칙
  - 화면(Playwright): 상세 열기·닫기, 항목 고치기, 쌓이는 입력 저장, 밀어서 삭제, 확인할 문자 등록·무시
