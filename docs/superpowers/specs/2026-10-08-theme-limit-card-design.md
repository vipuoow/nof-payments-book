# 화면 모드 · 한도 카드 · 이동 아이콘 · 체크 버튼 설계

작성: 2026-10-08 · 상태: 사용자 승인(시안 23~33판, "기기 설정 따르기는 빼고 앱에 적용해서 배포")

## 1. 화면 모드 (사람마다)

세 가지 모드가 있고, 처음과 로그인 전에는 기본 모드다. 휴대폰 다크 모드를 자동으로 따르지 않는다.

| 모드 | 모습 |
|---|---|
| 기본 | 흰색 → 아주 옅은 라벤더 그라데이션 배경 + 흰 카드(옅은 보랏빛 그림자) |
| 밝게 | 지금의 밝은 화면 |
| 어둡게 | 지금의 어두운 화면 |

기본 모드 색:

| 쓰임 | 색 |
|---|---|
| 글자 | `#221d36` |
| 보조 글자 | `#857f98` |
| 강조·버튼 | `#6a55d4` (흰 글자) |

- 저장: `profiles.theme`(`basic | light | dark`).
- 적용: 쿠키 `theme` → `<html data-theme>`.
- 쿠키를 맞추는 때: 로그인할 때, 모드를 바꿀 때.
- 설정 위치: 메뉴 › 화면 모드(`/settings/theme`). 누르면 바로 바뀌고 저장한다.

## 2. 한도 카드 (홈 맨 위, B안)

```
‹ 9월      2026년 10월      (다음 달 ›)
한도 200만 원 중
1,280,000원 썼어요                ← 금액만 크게, 상태색
남편 740,000원 | 아내 540,000원
[■■■■■■■■■■■■■   72만 원 남음]    ← 굵은 막대(끝까지=한도), 남은 칸 안 글자
```

**상태색(한도 사용률)**

| 사용률 | 색 |
|---|---|
| 50% 이하 | 녹색 |
| 85% 미만 | 노랑 |
| 85% 이상 | 빨강 |

**막대 안 글자**

| 남은 돈 | 막대 안 글자 |
|---|---|
| 한도의 10% 이상 | "N원 남음"(한글 단위) |
| 0 초과 ~ 10% 미만 | 거의 다 썼어요 |
| 0 | 다 썼어요 |
| 초과, 130% 미만 | 우리 다음 달을 생각해요 |
| 130% 이상 | 슬픈 결제일이 될 것 같아요 |

- 70% 넘게 쓰면 남은 칸이 좁아 글자를 색 막대 끝 안쪽(흰 글자)으로 옮긴다.
- 사용률 퍼센트는 보여 주지 않는다.
- 카드를 손가락으로 옆으로 밀면 달이 바뀐다. 이번 달보다 뒤로는 못 간다.
- 카테고리 예산 경고 줄은 지금처럼 카드 아래에 둔다.

## 3. 이동·닫기 아이콘

- 이동 링크는 글자 없이 아이콘만 둔다(‹ 홈, ‹ 한도 등). 화면 읽기용 이름은 남긴다.
- 아이콘은 약 4% 키운다.
- 한도 카드의 "‹ 9월"은 글자를 그대로 둔다.
- 겹쳐 뜨는 화면의 "✕ 닫기"는 글자 없이 큰 X로 바꾼다(26px, 누르는 자리 44px).

## 4. 체크되며 넘어가는 버튼

- 대상: 다음·고쳤어요·다 입력했어요·저장하기·확인
- 누르면 버튼이 56px 원으로 줄어들며 ✓가 그려진다.
- 동시에 버튼 자리에서 보라 빛(옅은 물결 + 빛 고리)이 화면 전체로 번진다(약 0.9초).
- 그 뒤 화면이 넘어간다.
- 검사에 걸리면 체크하지 않고 안내만 한다.
- 저장에 실패하면 버튼을 되돌린다.
- 동작 줄이기 설정에서는 움직임 없이 바로 넘어간다.

## 5. 확인할 문자 알림줄

- 낮은 흰 줄로 바꾼다.
- 앞의 보라 점이 2.4초마다 은은하게 깜빡인다.

## 하지 않는 것

- 기기 설정 따르기
- 분류할 거래·카테고리 관리(22판, 별도)
- 많은 거래 로딩 화면(나중에)
